WEEK 5 · CUSTOM PROPERTIES

Design tokens turn a client’s scope change into a small edit

  • Name colors, spacing and type sizes once, in :root
  • Rules use var(--name), never raw values
  • Practice: restyle a whole page by editing :root only
  • This is the habit that absorbs the mid-day scope change

:root {

  --color-ink: #1d2433;

  --color-accent: #b4451f;

  --space-m: 1rem;

  --step-1: 1.25rem;

}

.button {

  background: var(--color-accent);

  padding: var(--space-m);

}

Phase 1 spike · HTML and CSS

The week 5 build: give students a finished page and a new brand palette. They may change only the :root block. Any rule with a raw color value is a defect to log. CSS variables are also a named exam topic.
