WEEK 6 · EXIT CHECK

The exit check: three functions on a services array

Conditions

L2, no AI, 60 minutes, shared with the HTML part of the check

Task

Given an array of 10 service objects, write functions that filter by category, sort by name and count per category

Pass

Correct output on the coach’s test calls; a two-sentence explanation of each function

Phase 1 spike · JavaScript

The coach’s test calls should include an empty array and a category with no matches, so the check also tests edge cases. The explanation part rehearses the Phase 3 interview: students must explain code they wrote without help.
