WEEK 5 · HIGHER-ORDER FUNCTIONS

Array methods shape what the page shows

  • filter keeps items; map changes each one
  • reduce folds a list into one value, such as counts
  • toSorted returns a new array; sort changes the original
  • Each step returns a new array, so steps chain

const food = services

  .filter((s) => s.category === "food");

const names = services

  .map((s) => s.name)

  .toSorted();

const counts = services.reduce((acc, s) => {

  acc[s.category] = (acc[s.category] ?? 0) + 1;

  return acc;

}, {});
