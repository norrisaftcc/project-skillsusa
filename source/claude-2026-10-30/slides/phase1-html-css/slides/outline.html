WEEK 2 · STRUCTURE

Landmarks give the page an outline a screen reader can use

  • One h1; headings in order, no skipped levels
  • header, nav, main and footer before any div
  • Navigation is a list of links
  • Every page passes the W3C HTML checker

<body>

  <header>

    <nav aria-label="Main">

      <ul><li><a href="/">Home</a></li></ul>

    </nav>

  </header>

  <main>

    <h1>Community Resource Desk</h1>

  </main>

  <footer>…</footer>

</body>

Phase 1 spike · HTML and CSS

Model this at L4 first: write the outline live, then ask students to predict what a screen reader’s landmark list shows. The judging area “semantic and accessible code” starts here. Students who reach for div first should rebuild with landmarks before moving on.
