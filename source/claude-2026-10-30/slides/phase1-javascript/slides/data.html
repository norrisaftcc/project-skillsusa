WEEK 4 · OBJECTS AND ARRAYS

A site’s content lives in an array of objects

  • The same shape as a list of dicts
  • Dot access: s.name (s["name"] also works)
  • A missing key gives undefined, not an error
  • This array feeds the Phase 2 card and filter builds

const services = [

  { name: "Food pantry",

    category: "food", open: true },

  { name: "Tax help",

    category: "money", open: false },

];

services[0].name; // "Food pantry"

services.length;   // 2

services[0].hours; // undefined
