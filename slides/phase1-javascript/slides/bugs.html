WEEK 6 · BUGS AND ERRORS

Debugging is a skill we practice on purpose

  • Find and fix five planted bugs
  • Read a console error: message, file, line
  • Write three test calls for every function
  • Look for undefined and NaN, not only thrown errors

"use strict";

function average(nums) {

  let sum = 0;

  for (const n of nums) sum += n;

  return sum / nums.length;

}

console.assert(average([2, 4]) === 3);

console.assert(average([]) === 0);

// fails: average([]) is NaN

Phase 1 spike · JavaScript · Eloquent JavaScript ch. 8

The empty-list case is the point: JavaScript returns NaN where Python raises ZeroDivisionError. The test call finds it. Students log every bug they find and how they found it; the log becomes interview material in Phase 3.
