# FTCC SkillsUSA 2026–27 Verified Baseline

As of 30 October 2026. Live, editable version: [Claude Doc](https://claude.ai/artifact/NbhGoeMAjN5PPrZhsknyvf).

## How to read this document

This document holds only facts that a public official or primary source states. Each fact names its source. Each gap is written as what we know, then an **Open** item that says what to confirm and with whom.

- **Documented** text is a fact from a current official source: skillsusa.org, skillsusanc.org, Web Professionals Global (WPG), webprocontests.org, or faytechcc.edu.
- **Baseline (2024–26)** marks a fact from the previous national Technical Standard. The 2026–28 standards are in force but are member-only. Check each baseline fact against the 2026–28 text.
- **Open** marks a fact we do not have yet. Each Open item names who can answer it. All Open items are also listed in the last section.

The 2026–28 Technical Standards are available only to members through Pathful. Do not copy them into any public page or site. Link to the official access page instead.

## Eligibility, membership and fees

Every competitor must be a paid SkillsUSA member by 1 March 2027. Student dues in NC are $14 and professional dues are $26.

**Eligibility (Documented, [General Regulations](https://www.skillsusa.org/wp-content/uploads/2023/10/SkillsUSA-Championships-General-Regulations-2023-24.pdf)):**

- A postsecondary competitor must be in a coherent program of study and progressing toward a postsecondary credential in the year before NLSC.
- Work-based learning counts only when it carries credit.
- The advisor needs professional membership to get Pathful access to the Technical Standards.

**Dues (Documented, [SkillsUSA NC](https://skillsusanc.org/join)):**

| Member type | National | NC state | Total |
| --- | --- | --- | --- |
| Student (college/postsecondary) | $8 | $6 | $14 |
| Professional (advisor) | $20 | $6 | $26 |

NC also offers a Campus Affiliation Plan for colleges. Under such a plan, a college affiliates programs or the whole campus on one contract instead of paying individual dues.

**Open:** Does FTCC use the Campus Affiliation Plan, or does each member pay dues? Ask Wil van der Meulen, NC Postsecondary Support Director.

**Event fees:** In 2026, NC charged these fees ([regional rallies](https://www.skillsusanc.org/regional-rallies), [state conference info](https://www.skillsusanc.org/state-conference-information)):

| Fee | 2026 amount |
| --- | --- |
| Regional rally, per person (student or advisor) | $20 |
| State registration, member who competed at a regional rally | $60 |
| State registration, member who did not compete at a regional rally | $85 |
| Late addition | $25 each |
| Change after the drop deadline | $25, or $50 onsite |
| Card payment surcharge | 4% |

The school must pay its balance before its students can compete.

**Open:** The 2027 fee amounts. They will appear in the 2027 Conference and Competition Packet.

## Computer Programming (individual, postsecondary)

Computer Programming is an individual contest. It has a knowledge test, three or four programming projects and an interview. Each state can send one postsecondary entry to nationals.

All facts in this section are **Baseline (2024–26)** from the [2024–26 national Technical Standard](https://resources.finalsite.net/images/v1731606870/mntechnologycom/zuf7qkvhzy47udu1mk51/ComputerProgramming2024-26.pdf), unless marked otherwise.

| Part | What the standard says |
| --- | --- |
| Eligibility | Active members in programs where computer programming is a job goal. One postsecondary entry per state at nationals. |
| Scope | Competencies identified by CompTIA. |
| Knowledge test | Covers Java, C, C++, C#, Python, Ruby, JavaScript, PHP, Objective-C and SQL, "but not limited to" these. |
| Skill performance | A packet of three or four projects. Each project gives design notes and instructions in one language. The competitor must produce a program that runs. |
| Scoring criteria | Completeness, correctness of output, validation of input, internal documentation, efficiency of code, quality of work. No weights are published. |
| Interview | Questions for an entry-level computer programmer position. |
| Competency areas | Programming concepts; Java; C++ (including pointers and sequential files); Visual Basic .NET (files, database controls, GUI); SkillsUSA Framework. |
| Committee supplies | Printer, programming instructions, timing and judging procedures. |
| Competitor brings | Desktop with monitor, or laptop. Software to write and run code in the chosen language. One coding reference manual (paper or digital). Pens or pencils, blank paper, one 6-foot surge protector. |

**NLSC 2027 conditions (Documented, [competition updates](https://www.skillsusa.org/competitions/skillsusa-championships/competition-updates/)):**

- Internet access is not permitted during competition unless the committee authorizes it.
- Pre-install fully licensed software that runs offline.
- Competitors need admin rights on their own machines.
- NLSC Wi-Fi is mainly 5 GHz.
- No Computer Programming update was posted as of the 22 October 2026 page revision.

**Languages.** The 2024–26 competency areas name Java, C++ and Visual Basic .NET. Python appears only in the knowledge-test list.

**Open:**

- What does the 2026–28 standard list as competency languages? Is Python permitted for the projects? Read the 2026–28 standard in Pathful.
- Does NC state allow Internet, IDE autocomplete or AI assistants? How many reference manuals? Is there a written test and an interview at state? Ask SkillsUSA NC.
- How many Computer Programming entries per school does NC accept at state? Check the 2027 NC contest spreadsheet.
- Is the national knowledge test given online before NLSC? Watch for a competition update by 18 May 2027.

## Web Design and Development (team of two)

Web Design and Development is a two-person team contest that Web Professionals Global (WPG) has run with SkillsUSA since 2004. It has a one-hour online exam and a one-day live client project. NC lists the contest as "Web Design."

**Format (Documented, [WPG 2026 recap](https://webprofessionalsglobal.org/2026-skillsusa-national-web-design-and-development-competition-recap/), [2023–24 standard](https://resources.finalsite.net/images/v1700063899/gcitorg/xarycrundehj64ktd4ef/WebDesignandDevelopment2023-24.pdf)):**

1. A one-hour online written exam. At NLSC 2026 it ran in a noon to 2 p.m. session.
2. A technical orientation on the WPG cloud IDE.
3. A live client interview. The client in 2025 and 2026 was David Jackson.
4. One hour of paper planning: low-fidelity wireframes, site maps and mood boards. In 2026, teams drew their own wireframes.
5. Coding in a server-based environment that WPG supplies.
6. A change of scope from the client after lunch.
7. Team interviews while coding continues. Questions in 2026 covered design decisions, wireframe process, and why the client should hire the team.

In 2026, the secondary contest day ran from 8 a.m. to 3 p.m. The postsecondary contest day ended at 3 p.m.; WPG gives no start time. Secondary and postsecondary teams compete on different days.

**Open:** The time for each phase after the paper hour. No official source gives coding sprint lengths or a code freeze. Ask the contest chair or read the 2026–28 standard.

**Rules (Documented, same sources):**

- No templates. All work is created during the contest.
- Copyright violations mean disqualification.
- No front-end frameworks. WPG names Bootstrap, Tailwind and React as examples.
- No AI generation assistance.
- Judges use an online portal. It shows source code, runs validation and renders mobile and tablet viewports.

**Open:** Whether other libraries (for example jQuery) and CSS preprocessors are also banned. Treat them as banned until the 2026–28 standard says otherwise.

**Written exam (Documented, [CWDSA blueprint](https://webprofessionals.org/certification/cwdsa/)).** The national standard ties the exam to the WPG Certified Web Designer Associate-apprentice (CWDSA) certification. That exam has 70 questions in 60 minutes.

| Domain | Weight |
| --- | --- |
| HTML | 25% |
| CSS | 25% |
| Web graphics | 10% |
| UX and UI design | 10% |
| Accessibility and WCAG | 10% |
| Internet basics | 6% |
| Web audio and video | 5% |
| Security basics | 3% |
| Project management | 3% |
| Legal and business issues | 3% |

**Open:** Whether the contest exam uses the same 70-question format. The blueprint names WCAG but no version; confirm which version judges apply.

**Judging.** WPG listed three public judging areas for 2026: UX and UI layout and responsiveness; semantic and accessible code; teamwork and agency professionalism. SkillsUSA posts sample rubrics for members (updated September 2026). WPG gives its yearly rubric to teachers through SkillsUSA.

**Open:** The point weights for each judging area. Get the current rubric from SkillsUSA before you weight any practice scores.

**Equipment (Baseline, 2023–24 standard):** The committee supplies table space and power. Each team brings two surge protectors, a sketch pad, computers with 5 GHz or Wi-Fi 6, and its own wireframing and documentation tools.

**Open:**

- How does NC run its state Web Design contest? WPG's [2026 state recap](https://webprofessionalsglobal.org/category/web-competitions/) lists 11 states it ran contests for, and NC is not one of them. Ask SkillsUSA NC who writes the project, provides the IDE and judges.
- Does NC keep the team size at two? Check the 2027 NC contest spreadsheet.

## Rules for both contests

Both contests use Class E business casual attire, require a one-page resume, and require the Professional Development Test for national competitors.

| Rule | National (NLSC) | NC state |
| --- | --- | --- |
| Attire | Official white SkillsUSA polo; black dress slacks or black dress skirt (knee length minimum); black closed-toe dress shoes. Socks are not required; if worn, they must be black dress socks. Wear contest attire to orientation. | Same attire. The white polo need not carry the SkillsUSA logo. Cover any school or business logo. Attire is required at the contest and at the opening and awards ceremonies. |
| Resume | One-page PDF uploaded by 3 June 2027, 5 p.m. ET. A missing upload incurs a penalty; the 2027 page gives no point value. (The 10-point penalty on that page is for a missing Safety Training Verification Letter.) Web Design also needs a hard copy at orientation. | Hand a paper resume to the contest chair at the contest. Penalty points apply if it is missing. |
| Professional Development Test (PDT) | Online, before NLSC. Due 17 June 2027, 5 p.m. ET. | Not given at state in 2026. Required only for national qualifiers. |
| Devices | Phones, smartwatches and unapproved electronics are banned. Misuse can cost the score. | Phones and unapproved electronics are banned. Test any computer you bring for software access away from campus. |

## NC and FTCC logistics

FTCC hosts the South Central Regional Rally on 19 February 2027, and first place at the NC state conference qualifies a student or team for nationals.

**Path to nationals (Documented, [SkillsUSA NC](https://www.skillsusanc.org/skillsusa-membership-deadline)):**

1. Regional rally (optional practice; it also lowers the state registration fee).
2. NC State Leadership and Skills Conference, 21–23 April 2027, Greensboro.
3. First place in a national contest at state qualifies for NLSC. If the winner is not eligible (for example, joined after 1 March), NC moves the spot to the next finisher.
4. NLSC, 21–25 June 2027, Atlanta.

**Regional rally.** NC regional rallies are optional one-day events. Each rally offers a limited contest list.

**Open:**

- Are Computer Programming or Web Design offered at the 19 February rally at FTCC? Ask the rally host or SkillsUSA NC.
- Must postsecondary students compete at a regional rally to enter state? We found no rule that requires it. Confirm with Wil van der Meulen.
- Do both contests run at the Greensboro conference site, or off-site? On which day and at what times?

**FTCC chapter (Documented, [faytechcc.edu](https://faytechcc.edu/skills-usa/)).** FTCC has an active chapter in the Tony Rand Student Center, Room 124-A, 2201 Hull Road. At the 2026 NC state conference, [23 FTCC students placed in 18 categories](https://faytechcc.edu/ftcc-students-shine-at-skillsusa-north-carolina-state-conference/), and the chapter earned bronze Chapter of Distinction. Reported FTCC wins are in trades, cosmetology, culinary and 3-D Visualization and Animation. We found no FTCC results in Computer Programming or Web Design.

**The gate opens when both conditions are true:**

- [ ] The advisor has downloaded the 2026–28 Technical Standards for Computer Programming and for Web Design and Development from Pathful.
