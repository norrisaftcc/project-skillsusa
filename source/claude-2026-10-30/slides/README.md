These files are a snapshot of 30 October 2026. If someone edits a live deck, this copy does not update; replace the folder with a fresh export.

## What the decks are for

An overview of Phase 1 (weeks 2–6) for review, not the full lesson set. Each deck ends with a coverage slide and five open questions. The gaps they found:

- **HTML and CSS:** specificity and the cascade, data tables, iFrames and entities, relative file paths, CSS units, positioning with transitions and transforms, and what LESS and Sass are. These are exam topics with no Phase 1 build yet.
- **JavaScript:** string methods for search, converting form input to numbers, JSON, and template literals in real output. Phase 2 builds need them; Phase 1 does not yet teach them.
