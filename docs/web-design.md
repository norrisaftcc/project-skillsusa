## What happens on the day

Web Professionals Global (WPG) has run the national contest with SkillsUSA since 2004. At the 2026 national contest the order was:

1. **Written exam.** One hour, online, before the build day.
2. **Orientation** on the WPG online coding environment.
3. **Live client interview.** The team asks the client questions.
4. **One hour of paper planning.** Wireframes, a site map and a mood board, on paper. In 2026 each team drew its own wireframes.
5. **Coding** in a browser-based environment that WPG supplies.
6. **A change from the client after lunch** (WPG calls it a "twist").
7. **Team interviews while coding continues.** In 2026 the questions covered design decisions, the wireframe process, and why the client should hire the team.

Status: {% include status.html s="confirmed" %} for 2026. Sources: [WPG 2026 recap](https://webprofessionalsglobal.org/2026-skillsusa-national-web-design-and-development-competition-recap/), [2023–24 standard (public copy)](https://resources.finalsite.net/images/v1700063899/gcitorg/xarycrundehj64ktd4ef/WebDesignandDevelopment2023-24.pdf).

**Times.** In 2026 the high school day ran from 8 a.m. to 3 p.m. The college day ended at 3 p.m.; WPG gives no start time. No official source gives the length of each coding phase. {% include status.html s="unverified" %}

**NC state contest.** We do not know yet how NC runs it: who writes the project, who supplies the coding environment, and who judges. WPG's list of 2026 state contests does not include NC. {% include status.html s="unverified" %}

**How we practice:** plain HTML, CSS and JavaScript, from blank files, with no AI, no frameworks, no libraries and no templates. {% include status.html s="local" %} This is the safe choice whatever the 2027 rules say. A team that can build without help can still use help if the rules allow it.

## Judging

WPG gave three public judging areas for 2026 national medalists:

1. UX and UI layout and responsiveness.
2. Semantic and accessible code.
3. Teamwork and agency professionalism.

Status: {% include status.html s="confirmed" %} for 2026 ([WPG 2026 recap](https://webprofessionalsglobal.org/2026-skillsusa-national-web-design-and-development-competition-recap/)). Judges use an online portal. It shows the source code, runs validation checks and shows the site in phone and tablet sizes.

The official rubric and its point weights are member material. Coaches get them through SkillsUSA. For practice we use our own rubric: see the [practice scorecard]({{ '/practice/scorecard/' | relative_url }}). {% include status.html s="local" %}

## Written exam

The national standard ties the exam to the WPG Certified Web Designer Associate-apprentice (CWDSA) certification. The CWDSA exam has **70 questions in 60 minutes**. {% include status.html s="confirmed" %} for the certification ([CWDSA page](https://webprofessionals.org/certification/cwdsa/)).

Whether the 2027 contest exam has the same format is {% include status.html s="unverified" %}. Study the CWDSA topics anyway: they are the best public guide to what the exam covers.

| Domain | Weight in the CWDSA exam |
|---|---|
| HTML | 25% |
| CSS | 25% |
| Web graphics | 10% |
| UX and UI design | 10% |
| Accessibility and WCAG | 10% |
| Internet basics | 6% |
| Web audio and video | 5% |
| Security basics | 3% |
| Project management | 3% |
| Legal and business issues | 3% |

Half of the exam is HTML and CSS. Both team members take the exam, so both must know HTML and CSS well, even the designer. {% include status.html s="local" %}
