# Student Field Manual & 10-Lab Catalog

Web Design and Development | Original SkillsUSA preparation material

## Practice routine

Read the client request and isolate the user, required data and constraints. Sketch a small-screen hierarchy. Build semantic HTML before decorative details. Add responsive CSS and minimal JavaScript for the specified behavior. Test at 320px, 768px and desktop width; complete a keyboard-only visitor task. Record a defect, repair and retest. Explain one requirement by pointing to its code and a successful test.

## Skill clinics

| Lab | Title | Time | Task |
|---|---|---|---|
| LAB-01 | Client questions and wireframes | 25 min | Five discovery questions, three acceptance criteria and a mobile layout sketch. |
| LAB-02 | Semantic structure | 35 min | Page landmarks, headings, anchor navigation and unique IDs. |
| LAB-03 | Accessible contact form | 40 min | Labels, validation text and keyboard submission. |
| LAB-04 | Responsive card layout | 40 min | Grid/Flexbox cards at three widths with no overflow. |
| LAB-05 | CSS cascade and focus | 35 min | Fix competing selectors; prove keyboard focus remains visible. |
| LAB-06 | Category filter | 45 min | Filter six records with a native select; update the visible count and restore All. |
| LAB-07 | Accessible disclosure | 45 min | Build an FAQ disclosure with native details/summary or a correct stateful button. |
| LAB-08 | Images and alternatives | 35 min | Preserve aspect ratio, verify local paths and provide proper alternative text. |
| LAB-09 | Search and data accuracy | 35 min | Data-driven search, case-insensitive matching and a helpful empty state. |
| LAB-10 | Repair and regression | 50 min | Diagnose five common defects and prove each fix. |

## Submission standard

Submit source files, short client notes, a mobile wireframe and EVIDENCE.md. The evidence includes a passed test, a failed test, a repair, keyboard and narrow-screen checks, and a known limitation. All instructor references, answers and surprise changes must remain outside the student work area.

## Independent practice conditions

Our local independent exercises use plain HTML, CSS and JavaScript without AI code generation or external page templates. The official contest rules may differ and override these training conditions.
