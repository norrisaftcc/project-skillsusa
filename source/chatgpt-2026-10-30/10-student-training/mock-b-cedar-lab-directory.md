## Acceptance criteria

1. Semantic page structure, primary navigation, exact six workshop records and accessible controls.
2. Topic selector with All, Web, Coding and Career.
3. Text search that matches workshop titles without case sensitivity.
4. Combine both filters correctly; show accurate visible count.
5. Empty-state message when no workshop matches.
6. Reset control clears both fields and restores all six records.
7. Work at 320px, 768px and desktop with keyboard focus, no horizontal overflow or JavaScript errors.
8. Submit EVIDENCE.md with six or more tests, one repaired defect and a short explanation of data handling.
