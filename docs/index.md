## How to read a rule on this site

Each rule has one of three labels.

| Label | Meaning |
|---|---|
| {% include status.html s="confirmed" %} | A public official source states it. The page names the source. |
| {% include status.html s="unverified" %} | No current official source confirms it yet. It can come from an older standard or from the 2026 contest. Prepare for it, but do not depend on it. |
| {% include status.html s="local" %} | Our own practice rule or advice. It is not a contest rule. |

The 2026–28 SkillsUSA Technical Standards are for members only. They may not be posted in a public place, so this site does not quote them. Members get them through [Pathful](https://www.skillsusa.org/competitions/skillsusa-championships/technical-standards/).
