WEEK 3 · FUNCTIONS

Functions are values, and they remember where they were made

  • Function declarations and arrow functions
  • let and const live inside their block
  • A closure keeps its outer variables
  • Drill: predict the output, then run it

function makeCounter() {

  let count = 0;

  return () => {

    count += 1;

    return count;

  };

}

const next = makeCounter();

next(); // 1

next(); // 2
