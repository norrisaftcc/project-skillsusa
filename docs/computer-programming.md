## Contest parts

All from the 2024–26 standard. {% include status.html s="unverified" %} for 2027.

| Part | What the standard says |
|---|---|
| Knowledge test | Covers Java, C, C++, C#, Python, Ruby, JavaScript, PHP, Objective-C and SQL, "but not limited to" these. |
| Programming projects | A packet of three or four projects. Each project gives design notes and instructions for one language. The competitor must produce a program that runs. |
| Interview | Questions for an entry-level programmer job. |
| Professional Development Test | Required for national competitors. See [Dates]({{ '/dates/' | relative_url }}). |

## How projects are scored

Six criteria from the [2024–26 standard](https://resources.finalsite.net/images/v1731606870/mntechnologycom/zuf7qkvhzy47udu1mk51/ComputerProgramming2024-26.pdf). No weights are published. {% include status.html s="unverified" %} for 2027.

1. Completeness.
2. Correctness of output.
3. Validation of input.
4. Internal documentation (comments).
5. Efficiency of code.
6. Quality of work.

**How we practice:** score every practice program on all six. Make input validation and comments a habit, not an extra. {% include status.html s="local" %}

## Languages

The 2024–26 competency areas name **Java**, **C++** (including pointers and sequential files) and **Visual Basic .NET** (files, database controls, GUI). Python appears only in the knowledge-test list. {% include status.html s="unverified" %} for 2027.

Pick one main language early and train in it under contest conditions. {% include status.html s="local" %} The choice waits for the advisor's check of the 2026–28 language list.

## What to bring

From the 2024–26 standard. {% include status.html s="unverified" %} for 2027.

- A desktop with a monitor, or a laptop.
- Software to write and run code in your language.
- One coding reference manual (paper or digital).
- Pens or pencils, blank paper and one 6-foot surge protector.

The committee supplies a printer, the programming instructions, timing and judging.

## Conditions at nationals in 2027

These apply to all NLSC 2027 contests. {% include status.html s="confirmed" %} ([competition updates](https://www.skillsusa.org/competitions/skillsusa-championships/competition-updates/), checked 6 Nov 2026).

- Internet access is not permitted during competition unless the committee authorizes it.
- Pre-install fully licensed software that runs offline.
- You need admin rights on your own computer.
- The conference Wi-Fi is mainly 5 GHz.

**How we practice:** build the contest laptop now. Test it offline and away from campus. NC warns that school IT locks have blocked students before. {% include status.html s="local" %}
