# Web Development — Baseline 01 Coach Guide

Internal instructor resource | Not an official SkillsUSA rubric

## Goal and assessment

Assess baseline independent ability to translate a brief into a small semantic, responsive, interactive website. Observe how students plan and test, not only the final screenshot.

## Suggested checkpoints

- Minute 10: ask the student to explain intended information hierarchy and mobile layout.
- Minute 60: ask them to demonstrate filtering and the primary visitor task.
- Minute 90: score the built website and read NOTES.md.
- Optional pivot: reveal the Saturday emergency referral notice and give 20 minutes to change the site without breaking working features.

## Local 100-point rubric

- Required factual content and filtering: 25
- Responsive presentation and visual hierarchy: 20
- Semantic HTML and keyboard accessibility: 20
- Planning and user needs: 15
- Testing and defect repair: 10
- Student explanation and work handoff: 10

Total: 100 — locally authored practice rubric, not official SkillsUSA weighting.

## Manual acceptance checks

- Try All services and each category; the expected visible card counts are 3 or 1.
- Open the page from local files; inspect console and network failures.
- Test 320px viewport and a wide desktop viewport; no sideways content overflow.
- Use Tab and Shift+Tab to reach navigation, category filter, and every contact link. Focus must stay visible.
- Read the page structure, heading order, card headings, and form label. Confirm service content exactly matches the student brief.
- If the pivot was assigned, verify the Saturday announcement is clear without changing weekday hours.

## Evidence log

Record time, completed requirements, keyboard/mobile defects, observed repair steps, and confidence in independent work. Add a short note about how the student explains JavaScript and CSS decisions.

## Deliverables and reference code

The project ZIP contains student starter files, the instructor reference website and a limited structural check script. The check script cannot prove WCAG compliance or actual responsive behavior; use manual browser testing.
