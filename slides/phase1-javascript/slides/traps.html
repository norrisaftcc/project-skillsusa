WEEK 2 · TRAPS

Three traps catch Python programmers first

== converts types

"1" == 1

// true

Fix: always use ===

Empty arrays are truthy

if ([]) { /* runs */ }

// Python: if []: does not

Fix: test items.length

sort() compares text

[10, 9, 1].sort()

// [1, 10, 9]

Fix: pass (a, b) => a - b

Also on the list: undefined instead of KeyError, no integer division, and xs[-1] is undefined.

Phase 1 spike · JavaScript

Each trap gets a predict-then-run drill: students write their Python expectation first, then run the line in the console. Put these traps in every weekly quiz in Phase 1. They are the errors that cost time in a contest because they fail silently.
