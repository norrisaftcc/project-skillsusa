WEEK 3 · FORMS

Every input has a label, and the browser checks input first

  • The label’s for matches the input’s id
  • Use type, required and autocomplete before any JavaScript
  • GET versus POST is an exam topic: know when to use each
  • Button text says what happens

<form action="/contact" method="post">

  <label for="email">Email</label>

  <input id="email" name="email"

         type="email" autocomplete="email"

         required>

  <button type="submit">Send message</button>

</form>

Phase 1 spike · HTML and CSS

This form returns in Phase 2, week 9, when JavaScript adds checks and accessible error text. Build the HTML-only version now so students see how much the browser does without script. Exam topics here: forms, GET versus POST, validation.
